למה צריך את זה?

בכל יום, מיליוני אנשים לוחצים על קישורים מסוכנים שנראים לגיטימיים.

🎣

התחזות (Phishing)

אתרים שנראים כמו הבנק שלך, PayPal, או Google — אבל גונבים סיסמאות ופרטי אשראי.

🔗

קישורים מקוצרים

שירותי קיצור כמו bit.ly מסתירים את היעד האמיתי. לא ניתן לדעת לאן הקישור מוביל בלי ללחוץ.

💀

תוכנות זדוניות

לחיצה על הקישור הלא נכון יכולה להתקין תוכנה זדונית, כופר (Ransomware), או רוגלה (Spyware).

איך זה עובד

3 שלבי ניתוח אוטומטיים

מהיר כשאפשר, מעמיק כשצריך — והמחשב שלך לעולם לא נחשף.

1
בדיקה סטטית — API

בדיקת מוניטין מול מאגרי מודיעין

הקישור נשלח (כטקסט בלבד, ללא כניסה) ל-4 מאגרי מודיעין עולמיים במקביל. אם מזוהה כמסוכן — מחזירים תשובה מיידית.

🔵 VirusTotal 🟠 URLScan.io 🟢 Google Safe Browsing 🔴 PhishTank
2
ניתוח דינמי — Sandbox

ביקור בטוח בתוך קופסת חול

אם הקישור לא מוכר — מערכת Docker מרימה מכונה וירטואלית חד-פעמית, שנכנסת לאתר עם דפדפן מבודד, מצלמת את המסך, בודקת הפניות, תעודות SSL ורישום דומיין — ואז משמידה את עצמה.

🐳 Docker Container 🎭 Playwright Browser 📸 צילום מסך 🔒 בדיקת SSL 📋 WHOIS Lookup 🔥 השמדה עצמית
3
מנוע החלטה — Heuristics

ניתוח חכם ומתן פסק דין

6 חוקי זיהוי מנתחים את הנתונים: האם הדומיין דומה לבנק? האם יש מילות פיתוי? האם תעודת ה-SSL חדשה מדי? התוצאה: Safe / Suspicious / Phishing עם אחוז ביטחון.

שכבות אבטחה

בנוי מהיסוד להיות בטוח

6 שכבות הגנה מבטיחות שהמחשב שלך לא ייחשף לאיום.

🛡️

הגנת SSRF

חסימת IP פנימיים, סכמות מסוכנות, ו-credentials מוטמעים.

📡

רשת מבודדת

ה-Sandbox רץ ברשת Docker נפרדת — ללא גישה לשרת ה-API או למחשב המארח.

🔒

Cap Drop ALL

כל הרשאות Linux מוסרות מה-Container. אפס יכולות מיוחדות.

📄

מערכת קבצים לקריאה בלבד

Root FS של ה-Container הוא read-only. רק /tmp זמין לכתיבה (עם noexec).

👤

משתמש Non-Root

הדפדפן רץ כמשתמש sandbox (לא root) — הגנה מפני Privilege Escalation.

🔥

השמדה עצמית

force=True remove בבלוק finally — ה-Container מושמד גם אם קורה שגיאה.
